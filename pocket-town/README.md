# ぽけっとタウン

ドールハウス感覚で自由に遊べる、ブラウザ用の箱庭ゲーム（トッカ・ワールド風の遊び方）。
キャラクターも家具もアイテムもすべてコードで描いたオリジナルで、画像ファイルや外部ライブラリは使っていません。

```bash
npx http-server . -p 8080   # → http://localhost:8080/pocket-town/
```

## あそびかた
- **ドラッグ**：キャラクターやアイテムを持ち上げて好きな場所へ。空いている所をドラッグすると画面が横に動きます。
- **キャラクター**
  - いす・ソファ・ベンチに座る
  - ベッドで寝る（Zzz）
  - おふろに入る
  - すべり台をすべる
  - ブランコに乗る
- **食べもの**：キャラクターの上に落とすと、もぐもぐ食べてハートが出ます。
- **ぼうし・めがね・ふく**：キャラクターの上に落とすと着替えます。前に着ていたものはポンと飛び出します。
- **アイテム**：食べもの以外はキャラクターの上に落とすと手に持ちます。ごみ箱に入れると消えます。
- **タップ**
  - キャラクター：見た目を変えるエディター
  - 家具：冷蔵庫・クローゼットの開け閉め、電気、テレビ、ラジオ（音楽）、水道、コンロ、トイレ
  - お店：コーヒーマシン・ケーキケース・オーブン・アイスクリーム屋さん・服のラックから新しいアイテム
  - 木：りんごが落ちる
  - 試着室：ランダムにお着替え
  - 美容室の鏡：髪型チェンジ
  - プレゼント：何かが出てくる
- **上のボタン**：場所の移動、キャラクターの追加、昼／夜の切り替え、音のオン・オフ、リセット
- 遊んだ状態はブラウザに自動保存されます。

## 場所
こうえん / おうち（キッチン・リビング・寝室・おふろ）/ カフェ / ようふくや

## 構成
- `js/art.js` キャラクター・アイテム・パーティクルの描画
- `js/world.js` 背景・建物・家具（描画と、タップ・座る・棚・入れ物・照明の定義）・初期配置
- `js/game.js` 物理（重力・着地）、ドラッグ操作、保存、夜の照明、エディターUI
- `js/audio.js` WebAudio の効果音とラジオの音楽
