# BIOHAZARD ― 洋館脱出 ―

ブラウザで動く、初代バイオハザード風のサバイバルホラー。外部ライブラリなし（WebGL2 + WebAudio のみ）。

```bash
npx http-server . -p 8080   # → http://localhost:8080/biohazard/
```
`biohazard/index.html` を直接ブラウザで開いても動きます。

## 遊び方
洋館に閉じ込められた。**玄関の鍵** を見つけて脱出しよう。

| 操作 | キー |
|---|---|
| 移動（ラジコン操作） | W A S D / 矢印 |
| 走る / クイックターン | Shift / Shift+↓ |
| 構える | Space / 右クリック |
| 撃つ | F / Enter / 左クリック（構えずに押すと自動で構えて撃つ） |
| 調べる・拾う・扉 | E |
| リロード / 武器切替 / ハーブ | R / Q / H |
| アイテム / ポーズ | Tab / P・Esc |

スマホではバーチャルスティックとボタンが表示されます。

## 内容
- 固定カメラ＋ラジコン操作、構え時の自動照準、扉を開ける暗転演出
- 6部屋（玄関ホール・食堂・東の廊下・倉庫・書庫・地下研究室）、剣の鍵 → 盾の鍵 → 玄関の鍵の順に進行
- ゾンビ（死体に見えて起き上がる個体あり）、ゾンビ犬、ボス「G-01」
- ハンドガン / ショットガン、グリーンハーブ、ファイル3種、心電図ステータス
- 死亡時は部屋の入口からリトライ。クリア時にタイム・命中率などからランク評価
- 効果音・環境音・雷はすべて WebAudio で合成

## 構成
- `js/renderer.js` WebGL2 レンダラー（手続き的なマテリアル、点光源8灯、フォグ、フィルムグレイン）
- `js/world.js` マップ・扉・家具・照明・アイテム・敵配置・テキスト
- `js/entities.js` キャラクターのモデルとパーティクル
- `js/main.js` ゲームループ、AI、戦闘、カメラ、UI
- `js/audio.js` 効果音の合成
