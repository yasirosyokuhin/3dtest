# Anime Head Generator（顔のみ・第1段階）

Tripo のように **3Dメッシュ + テクスチャ** を出力する、アニメ調キャラクターの頭部ジェネレーターです。
外部ライブラリなし（Node.js のみ）で動きます。

![preview](output/previews/sheet.png)

## 出力（ゲーム向け）

| ファイル | 内容 |
|---|---|
| `output/anime_head.glb` | glTF 2.0 形式（約3MB、約45,000ポリゴン）。`Face` と `Hair` の2メッシュ・2マテリアルで、テクスチャは埋め込み済みです。頭頂からあごまで約24cm（m単位） |
| `output/anime_head_skin.png` | 顔のアルベドテクスチャ（2048²、AO焼き込み済み） |
| `output/anime_head_hair.png` | 髪のアトラステクスチャ（2048²、房ごとに独立したUVアイランド、AOと天使の輪を焼き込み済み） |

- **顔**：112×104 のクワッドグリッドを造形に沿わせて緩和した、クリーンな4角形トポロジーです（約23,000三角形）。UVは連続していて、継ぎ目は後頭部だけです。
- **髪**：48房のリボン状メッシュ。つむじから放射状に生やし、頭に沿って垂れ、毛先は内側に巻いています。1房あたり10×22のクワッドで、その下に頭皮キャップ（地肌を隠すメッシュ）があります。
- Unity / Unreal / Blender / three.js にそのまま読み込めます。頂点カラーは使っていません。トゥーン表示にするなら、インバーテッドハル（背面法線押し出し）のアウトラインがおすすめです（ビューアーで実装例を確認できます）。

## 可愛さのための設計

- 大きく丸い頭蓋と、低い位置にある大きな目。下顔は短くして頬を丸くしています。
- 描き込んだ目：瞳の縦グラデーション、下側の発光、ハイライト3〜4点、まつ毛の跳ね、二重線。
- 小さく開いた笑顔の口と舌、斜線入りのチーク。
- 顔・首・耳は継ぎ目のない1メッシュです（パーツを差し込んだパペット感が出ません）。

## 使い方

```bash
node src/build.js                 # 出力: output/（--res=0.012 --tex=2048 が目安）
node scripts/render.js            # 確認用のレンダー: output/previews/*.png（Playwright が必要）
npx http-server . -p 8080         # → http://localhost:8080/viewer/index.html?src=/output/anime_head.glb
```

ビューアー（`viewer/index.html`）は依存ライブラリなしの WebGL2 で動き、「アニメ調（アウトライン付き）／ライティング／クレイ＋ワイヤー」を切り替えられます。「GLB…」ボタンから任意の GLB も開けます。

## 構成

- `src/head.js` 顔の造形（SDF）
- `src/topo.js` クワッドグリッドのリトポロジー（シュリンクラップ＋緩和）
- `src/hair.js` 房の成長、リボン状メッシュ、頭皮キャップ、UVアトラス
- `src/bake.js` UV空間でのラスタライズによるテクスチャベイク（パディング付き）
- `src/paint.js` 顔パーツと髪のテクセルシェーダー
- `src/mesher.js` AO計算用の SDF グリッド
- `src/glb.js`, `src/png.js` 依存なしの GLB / PNG ライター
